# HalfDimensionalDungeon
This is the repository for a Pseudo 3D Dungeon Crawler

The idea is to create a dungeon crawler similar in vein to that of *Madō Monogatari 1-2-3* (1990) and *Phantasy Star* (1987). However, rather than the usual turn based combat, I instead will make battles an arcadey shmup similar to a grounded version of the *Touhou Project* or *Undertale*. A variety of powers and weapons will be available to use by swapping physical colored floppy disks into your Floppy Disk Drive.
