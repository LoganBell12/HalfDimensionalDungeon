# Decision Log
##PRE PLANNING (AKA I don't know the exact date... Around August and Early September)
### Disk Media Type
**Decision:** Use Floppy Disks

**Rationale:** I originally wanted to use ZIP DISKS instead of Floppy Disks but USB Zip Drives are too expensive. I already have a USB Floppy Drive.

### ENGINE
**Decision:** Use Unity to create a Dungeon Crawler.

**Rationale:** I have prior experience with C#. There is no reason to learn an entire new framework for this project as the requirements don't imply whether or not I should.

### Battle System
**Decision:** Utilize floppy disks to change magic type. transition from a turn based JRPG to an arcade shmup.

**Rationale:** While I would love to make a JRPG someday, I wanted to be unique. Plus I have stacks of floppy disk that are begging to be used. Thus, I thought it would be a fun idea. I decided a Shmup would be
appropriate because there is no tension to swapping disks when the battle is turn based. I want the user to panic while fumbling with the disks.

### Character System
**Decision:** I decided to use a character creator when I was originally planning on having one main character.

**Rationale:** Character creators are cool. Also I already made one and because it's 2d, it made it suffer and I never used it. I need to make my suffering justified. I did make the original main character a shop keeper though. So that's cool I guess.

**Alternative:** Bring back one character.
